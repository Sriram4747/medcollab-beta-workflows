# Chat experience — 3-phase plan (WhatsApp-smooth for medicos)

**Goal:** Non-tech doctors leave WhatsApp for Vocle without training.  
**Out of scope for now:** voice / video / huddles.

---

## Phase 1 — WhatsApp-style chat ✅

Swipe → quote · quoted bubble · long-press thread · DM + groups.

## Phase 2 — Social DM privacy ✅

Phone lookup · opt-in **Allow message requests from anyone** · request inbox · accept → DM.

## Phase 3 — Chat parity polish ✅ (tonight scope)

| Shipped | Detail |
|---------|--------|
| Tappable links | URLs in bubbles open externally |
| Copy | Long-press → Copy |
| Forward polish | Share with “Forwarded from …” + media URL |
| Richer reactions | Quick row + More sheet (clinical emoji set) |
| Jump to quote | Tap quote strip → scroll + highlight original |

**Deferred (Phase 3.1):** in-app forward picker, link unfurl cards, unread divider, channel sections/starred, schedule/remind later, desktop niceties.
