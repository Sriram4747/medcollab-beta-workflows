## Disposable execution and maintainability

The new modular `scripts/security-data` suite reuses the existing media network/environment guards and supervised real Express entrypoint in **local mode**, so real SDK is replaced before imports and its configuration predicate stays unconfigured. JWTs are issued locally to fixture subjects solely to exercise real middleware; no SMS/bypass authentication credit is claimed. OTP model tests invoke the real creator/verifier, with OTP_BYPASS=false in the route server. Models and MongoDB are real; direct model/handler probes are explicitly distinguished from real HTTP.

GitHub-hosted MongoDB7 runs in Docker network-none; runner shares only its loopback. Exact URI is `mongodb://127.0.0.1:27017/vocle_ci`; any Atlas/different database/provider/proxy config or credential file fails preflight. Runtime verifies only `lo`, no external route, and parent/backend transport guards report zero blocked attempts. Source mounted read-only; no production startup/dotenv. Empty initial collections are required; fixtures use existing synthetic phone conventions and journaled IDs. Cleanup deletes only exact IDs or generated OTP/inbox records bound to those synthetic identities, verifies zero collection residue and terminates the child. No collection-wide destructive reset or account enumeration.

Prerequisite, safety, startup, unexpected execution exceptions, incomplete runs and cleanup failures block workflow success. Application oracle differences remain observations. Artifacts contain field-presence flags, statuses/counts and source hashes; no raw users, phones, token/hash values, response bodies or child logs. Syntax, frozen manifests, guard self-test, YAML/fork/ref/no-secrets checks passed locally; Windows lacks Docker here, so no local full execution is claimed. All hosted steps including hygiene/upload/MongoDB stop succeeded in both runs. The final run verifies ttlMonitorEnabled=false in the disposable server; actual TTL sweeping/deletion latency is not credited as tested.
