# Repository Safety Rules

- `origin` (`Sriram4747/medcollab-beta-workflows`) is the experimental fork. Branch creation, commits, pushes, workflow changes, and other instructed experimentation are permitted only there.
- `upstream` (`mathiharan29/medcollab-beta`) is the original project and is read-only: never push, force-push, create branches, modify, or otherwise write to it.
- Use `upstream` only for read, fetch, pull, and compare operations.
- Never change the `upstream` remote URL or redirect a push to it.
- If an instruction could result in writing to `upstream`, stop and ask the user first.
